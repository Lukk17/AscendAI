This group turns the deployment posture into repeatable, scripted checks against a running stack, as numbered specs of the platform suite, so a later change cannot open a port, mount the Docker socket or re-enable anonymous access without a sweep noticing. Each new numbered spec takes the next free number of the platform suite when it is written, never a number fixed here, and follows the suite's spec and tasks-template format.
