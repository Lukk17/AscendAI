# Tasks

Every agent command runs from `apps/ascend-agent`. Windows PowerShell uses `.\gradlew.bat` with the same arguments. A unit test run is capped at about 3 minutes and an integration run at about 15 minutes. Nothing is committed until the owner says to commit. This change is build group 4, position 5 of the owner build order of 2026-10-04. Groups 1 to 7 start only after `close-agent-test-gaps`, `upgrade-spring-boot-4`, `add-keycloak-login`, `add-deployment-modules`, `add-shared-scheduler`, `add-chat-streaming-and-conversations`, `add-agent-skills`, `add-agent-subagents` and `add-agent-soul` are applied, which all land earlier. Every required edit of design.md, "Required edits to other changes", is made in its target change (checked on 2026-10-03). No task here waits for a company change: `add-tenant-policy` and `add-audit-and-gdpr-compliance` (build group 5) register their implementations later.
