# Tasks

Agent commands run from `apps/ascend-agent` (Windows PowerShell uses `.\gradlew.bat` with the same arguments). Host commands run from `apps/ascend-openclaw-host`. A unit test run is capped at about 3 minutes and an integration run at about 15 minutes. Nothing is committed until the owner says to commit. Groups 3 to 9 start only after the changes this one needs are applied (build group 4, position 10 of the owner build order of 2026-10-04, listed in the proposal). Every required edit of design.md, "Required edits to other changes", is made in its target change (checked on 2026-10-03). A task that names an earlier change uses it as applied. No task waits for a later change or for a company change (owner rule of 2026-10-04): the parts that did moved to the change that carries them (dependency fix of 2026-10-05). Load the skills in the proposal's Relevant Skills section first.
