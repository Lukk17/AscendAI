# Tasks

Every agent command runs from `apps/ascend-agent`. Windows PowerShell uses `.\gradlew.bat` with the same arguments. A unit test run is capped at about 3 minutes and an integration run at about 15 minutes. Nothing is committed until the owner says to commit. Every group starts only after `upgrade-spring-boot-4`, `add-deployment-modules`, `add-shared-scheduler` (the shared scheduler and the owner notification store), `add-agent-skills`, `add-agent-subagents`, `add-agent-soul` and `add-action-approvals` are applied, as the build order in proposal.md says (build group 4, position 13 of the owner build order of 2026-10-04), together with `add-keycloak-login`, `add-chat-streaming-and-conversations`, and `add-openclaw-plugin-host`, all of which land earlier. No e2e task of this change needs the scripted harness of `close-agent-test-gaps` any more (answer 91.3 of 2026-10-08). No task waits for a later or a company change (owner rule of 2026-10-04): the tasks that did moved to the change that carries them (dependency fix of 2026-10-05). Every test of timed work uses the `ManualScheduler` and `SettableClock` test support of `add-shared-scheduler` task 1.4 and never waits for real time. The tasks follow the owner answers of 2026-10-02: 38.1 (a chat write after outside content waits for one tap of approval), 38.2 (every report is sent at once, no digest) and 38.3 (no dollar limits, only count limits), and the zone `Europe/Warsaw`.
