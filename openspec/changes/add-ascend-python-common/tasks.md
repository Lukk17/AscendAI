Every Python command runs through the `.venv` of the folder it names (`.venv/Scripts/python.exe` on Windows, `.venv/bin/python` on Linux and macOS), never the system Python, and always as `python -m <tool>`. A unit test run is capped at about 3 minutes and a full service gate at about 10. A run that gets close to its cap is treated as stuck and diagnosed. Docker build, up and restart are the owner's to approve, one line each, before they run. Nothing is committed until the owner says to commit, and nothing is pushed. The tasks follow the owner's answers of 2026-10-03 recorded in `design.md`, which close all seven open questions (5, the rate limit defaults, by answer 60.4, and 6, the startup banner and the URI fetch guard, by answer 60.5).
