## 4. Sync freshness check

- [ ] 4.1 Implement the freshness check per design D19 as the system task `connector-freshness-check` of `add-shared-scheduler`, under that change's contract: its name in `SchedulerTaskName`, the cron `app.scheduler.system-tasks.connector-freshness-check.cron` (default `*/5 * * * *`, environment variable `APP_SCHEDULER_SYSTEMTASKS_CONNECTORFRESHNESSCHECK_CRON`) and `.time-zone` (default `UTC`, environment variable `APP_SCHEDULER_SYSTEMTASKS_CONNECTORFRESHNESSCHECK_TIMEZONE`), each written `${ENV:default}` in `application.yaml` and `- ENV=${ENV:-default}` on the `ascend-agent` service of `compose.yaml` (owner rule 98 of 2026-10-08), with no module marking. Each firing, run by exactly one agent instance, compares each enabled connector's `last_successful_sync_at` against its maximum sync age, sets or clears the connector's stale flag, records a run with trigger `FRESHNESS_CHECK` only on a state transition, and closes as `FAILED` with `interrupted` every `RUNNING` run whose connector lock of design D22 is free. Blocked by: `add-shared-scheduler`.
  verify: with the manual scheduler test helper of `add-shared-scheduler`, an integration test asserts that after moving the clock past the maximum sync age the connector reads as stale and exactly one `FRESHNESS_CHECK` run is recorded, and a second firing with no further change records no additional run.
- [ ] 4.2 Assert the check changes no document and calls no source.
  verify: integration test asserts that after the check marks a connector stale, its landed stored objects still exist, its chunks still carry their text and all metadata keys, a caller of the owning tenant still retrieves them, and the fake connector was not called during the check.
- [ ] 4.3 Assert a healthy connector is never marked stale, and that recovery clears the flag.
  verify: integration test with a connector syncing more often than its maximum sync age asserts the flag is never set, and a stale connector that then completes a successful sync has the flag cleared in that run and one transition run recorded.
