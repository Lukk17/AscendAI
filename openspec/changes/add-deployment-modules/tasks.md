## 10. End-to-end tests this change adds (written before task 8.3 runs)

Pass criteria are observable behaviour only: HTTP status, the response body, container state (`docker compose ps`, `docker inspect`), Prometheus series and persisted state in the object store and Qdrant, never a log line. A refused start is proved by the container's state and exit code, never by its message text. Each new numbered spec takes the next free number of its suite when it is written, never a number fixed here, and follows the suite's spec and tasks-template format. Only task 10.8 needs an AI model. Every other spec is deterministic, and every Bruno request asserts its result in its own `tests` script.
